# 30-Days-Cybersecurity-Journey

A public, day-by-day log of hands-on cybersecurity learning. One task a day, for 30 days — tracked in the open, wrapping up with a recap on LinkedIn on Day 30.

## Why this repo exists

I'm using these 30 days to build and sharpen practical cybersecurity skills through daily, documented practice — rather than passive reading. Writing everything down publicly keeps me honest about actually finishing each day's task, and gives me (and anyone following along) a clear record of how the skills built up over the month.

## How it's organized

- **`Day-01/` … `Day-30/`** — one folder per day. Each contains a `README.md` with that day's task, what I did, key takeaways, and any supporting files (scripts, configs, screenshots, reports) as proof of work.
- **`DAY_TEMPLATE.md`** — the template every daily folder is based on. Copy it into a new `Day-XX/README.md` to start the next day.
- **`PROGRESS.md`** — a running tracker table showing the status of all 30 days at a glance (Not Started / In Progress / Done), with a link to each day's folder.

## Goals

- Complete one focused cybersecurity task every day for 30 days.
- Keep momentum and accountability visible via `PROGRESS.md`.
- Share the full journey — what was covered and what I learned — on LinkedIn at Day 30.

## Follow along

- Check **[PROGRESS.md](./PROGRESS.md)** for the current status of the challenge.
- Each day's folder is self-contained — jump straight to any `Day-XX/README.md` to see that day's task and notes.
